DÉPLOIEMENT SUR NETLIFY (2 MINUTES)
-----------------------------------
  1. Allez sur https://app.netlify.com/drop
  2. Glissez-déposez le DOSSIER complet "netlify-deploy"
     (ou décompressez le .zip avant si vous l'avez en .zip)
  3. Attendez ~10 secondes
  4. Netlify vous donne une URL du type
     https://xxxx-yyyy-zzzz.netlify.app

C'est en ligne. Partagez l'URL avec Julie (Ojunix).


POUR PERSONNALISER L'URL
------------------------
  1. Créez un compte Netlify gratuit
  2. Site Settings → Change site name
  3. Tapez par exemple "imazia-ojunix-contrat"
  4. Nouvelle URL : https://imazia-ojunix-contrat.netlify.app


MISE À JOUR PLUS TARD
---------------------
  Si on modifie le contrat, glissez le NOUVEAU dossier au même
  endroit (onglet "Deploys" du dashboard Netlify) — l'URL reste
  identique mais le contenu est actualisé.


CONFIDENTIALITÉ
---------------
  Le contrat fonctionne 100 % côté navigateur. Les données saisies
  (noms des mariés, montants, JSON) ne quittent jamais l'ordinateur
  de l'utilisateur — Netlify ne reçoit jamais les données mariage.
